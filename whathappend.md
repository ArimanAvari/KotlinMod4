## Что сделано в задании 7

Сделан bind service, который генерирует случайное число от 0 до 100 каждую секунду.

На экране есть:
- текущее число;
- кнопка `Подключиться`;
- кнопка `Отключиться`.

## Что такое bind service в этом задании

Здесь сервис не запускается обычным `startService()`.

Вместо этого Activity подключается к нему через:

`bindService(...)`

После подключения Activity получает доступ к самому объекту сервиса через `Binder`.

## Как работает сервис

В `RandomNumberService` есть:
- `RandomBinder`
- корутина `randomJob`
- callback `onNumberChanged`

Когда происходит `onBind()`:
1. сервис возвращает binder;
2. запускает генератор чисел, если он ещё не работает.

Дальше внутри корутины раз в секунду выполняется:
- `Random.nextInt(0, 101)`
- вызов callback с новым значением
- `delay(1000)`

## Как Activity получает число

В `MainActivity` есть `ServiceConnection`.

Когда вызывается `onServiceConnected()`:
1. из `IBinder` достаётся `RandomBinder`;
2. через него получается ссылка на `RandomNumberService`;
3. Activity устанавливает listener через `setOnNumberChangedListener`;
4. listener обновляет текст на экране.

То есть связь идёт напрямую между Activity и сервисом.

## Что происходит при отключении

Когда пользователь нажимает `Отключиться`:
1. Activity снимает listener;
2. вызывает `unbindService(...)`;
3. сервис получает `onUnbind()`;
4. внутри сервиса останавливается `randomJob`.

Из-за этого после отключения числа больше не генерируются.

## Почему это именно bind service

Главная идея bind service в том, что UI не просто запускает сервис, а именно взаимодействует с ним напрямую через binder.

Здесь это видно по шагам:
- есть `ServiceConnection`;
- есть собственный `Binder`;
- Activity получает экземпляр сервиса;
- сервис отправляет данные назад в UI через callback.

## Что говорить на защите

Короткий вариант:

1. Activity подключается к сервису через `bindService`.
2. Сервис отдаёт binder, через который можно получить его экземпляр.
3. После подключения сервис раз в секунду генерирует случайное число.
4. Activity получает число через callback и показывает его на экране.
5. При отключении `unbindService()` останавливает генерацию.
