## Что сделано в задании 2

Сделан поиск дубликатов `json`-файлов по SHA-256 с параллельной обработкой, общим таймаутом и поддержкой отмены.

Вместо консольного ввода в Android-приложении используется экран с кнопками:
- обычный запуск поиска;
- запуск с коротким таймаутом;
- ручная отмена текущего поиска.

Для демонстрации я создаю тестовую папку внутри `filesDir/task2_demo`, чтобы приложение сразу можно было запустить и показать преподавателю без дополнительных файлов вручную.

## Как работает программа

1. В `onCreate()` находится и инициализируется весь UI.
2. Сразу вызывается `prepareDemoDirectory()`.
3. Эта функция создаёт папку `task2_demo` и несколько файлов:
- `orders_day1.json`
- `orders_day1_copy.json`
- `users_export.json`
- `users_export_backup.json`
- `weather_unique.json`
- `readme.txt`

Из них четыре `json`-файла образуют две группы дублей, а `readme.txt` специально нужен, чтобы показать: ищутся только `json`.

## Поиск файлов

В `findDuplicateGroups()` используется:

`rootDir.walkTopDown()`

Это рекурсивный обход папки и всех вложенных подпапок. Дальше фильтруются только файлы, у которых расширение `json`.

## Параллельная обработка

После того как список файлов найден, для каждого файла создаётся отдельная корутина через `async(Dispatchers.IO)`.

То есть хеш для всех файлов считается параллельно, а не по очереди.

Дальше вызывается `awaitAll()`, чтобы дождаться завершения всех задач.

## Вычисление SHA-256

Для каждого файла вызывается `computeSha256(file)`.

Внутри:
- создаётся `MessageDigest.getInstance("SHA-256")`;
- файл читается как поток байтов;
- байты добавляются в digest;
- в конце получается hex-строка.

Это и есть цифровой отпечаток файла. Если содержимое одинаковое, SHA-256 тоже будет одинаковый.

## Как находятся дубликаты

После подсчёта всех хешей собирается список пар:

`файл -> hash`

Потом этот список группируется по `hash`.

Если в одной группе больше одного файла, значит это дубликаты.

Итог хранится в `DuplicateGroup`.

## Таймаут

Вся операция запускается внутри:

`withTimeoutOrNull(timeoutMs)`

Если поиск не успел завершиться за заданное время, функция возвращает `null`.

Тогда на экран выводится:

`Поиск прерван по таймауту`

Это как раз требование задания.

## Отмена

Есть ещё и ручная отмена через кнопку.

Текущая задача хранится в `searchJob`.

Когда пользователь нажимает кнопку отмены, вызывается:

`searchJob?.cancel(...)`

Из-за этого корутины завершаются корректно, а приложение не падает.

## Почему таймаут хорошо демонстрируется

В `computeSha256()` добавлен `delay(900)`.

Это имитация работы с большими файлами. Благодаря этому:
- обычный запуск успевает завершиться;
- короткий таймаут стабильно показывает отмену;
- задание легче демонстрировать на защите.

## Что говорить на защите

Короткое объяснение:

1. Программа рекурсивно ищет все `json` в папке и подпапках.
2. Для каждого файла параллельно считает SHA-256.
3. Дубликаты определяются по одинаковому хешу.
4. Весь поиск обёрнут в `withTimeoutOrNull`, поэтому есть общий лимит времени.
5. При превышении лимита или ручной отмене поиск завершается без краша.
6. На экране можно показать и успешный поиск дублей, и сценарий таймаута.
