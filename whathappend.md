## Что сделано в задании 10

Сделан экран получения текущего адреса по координатам.

Что умеет приложение:
- запрашивает разрешения на геолокацию;
- показывает индикатор загрузки;
- получает текущие координаты через `FusedLocationProviderClient`;
- переводит координаты в читаемый адрес через `Geocoder`;
- показывает и адрес, и краткие `lat / lng`;
- обрабатывает ошибки: нет разрешения, выключена геолокация, адрес не найден.

## Какие основные части здесь есть

1. `FusedLocationProviderClient`
Используется для получения текущей геолокации.

2. `Geocoder`
Используется для обратного геокодирования, то есть для перевода координат в нормальный адрес.

3. `RequestMultiplePermissions`
Нужен для запроса `ACCESS_COARSE_LOCATION` и `ACCESS_FINE_LOCATION`.

## Как работает сценарий

Когда пользователь нажимает кнопку:

1. проверяются разрешения;
2. если разрешений нет, они запрашиваются;
3. если разрешения есть, проверяется включена ли геолокация;
4. если всё нормально, показывается `ProgressBar`;
5. приложение получает `latitude` и `longitude`;
6. потом через `Geocoder` пытается получить читаемый адрес;
7. адрес и координаты выводятся на экран.

## Как получаются координаты

Используется:

`locationClient.getCurrentLocation(...)`

То есть приложение не подписывается на постоянные обновления, а просто запрашивает текущее местоположение.

Это удобно для такого задания, где нужна одна кнопка и один результат.

## Как работает обратное геокодирование

После получения координат вызывается `reverseGeocode(...)`.

Внутри:
- создаётся `Geocoder`;
- для Android 13+ используется callback-версия;
- для старых версий используется обычный вызов в `Dispatchers.IO`.

Дальше адрес собирается из частей:
- улица;
- номер;
- город;
- регион;
- страна.

## Какие ошибки обработаны

1. Пользователь не дал разрешение
Показывается текст: `Разрешение на геолокацию не выдано`

2. Геолокация выключена
Показывается сообщение про необходимость включить GPS или сетевое определение

3. Координаты получить не удалось
Показывается отдельная ошибка

4. Адрес не найден
Тоже выводится понятный текст, а не падение приложения

## Что говорить на защите

Коротко:

1. Координаты получаются через `FusedLocationProviderClient`.
2. Разрешения на геолокацию запрашиваются через `RequestMultiplePermissions`.
3. После получения `lat/lng` используется `Geocoder` для обратного геокодирования.
4. Результат выводится на экран вместе с координатами.
5. Ошибки вроде отключённого GPS или отказа в разрешении обработаны вручную.
