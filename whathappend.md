## Что сделано в задании 6

Сделан background service с одноразовым таймером.

Сценарий работы:
- пользователь вводит количество секунд;
- нажимает `Запустить таймер`;
- сервис ждёт нужное время;
- потом показывает уведомление `Таймер завершён!`;
- после этого сам завершает работу.

## Из каких частей состоит решение

Есть два основных файла:
- `MainActivity`
- `OneShotTimerService`

`MainActivity` отвечает за ввод секунд и запуск сервиса.
`OneShotTimerService` отвечает за ожидание и показ уведомления.

## Как работает экран

На экране есть:
- `EditText` для ввода числа секунд;
- кнопка запуска;
- `TextView` со статусом.

Когда пользователь нажимает кнопку:
1. строка из `EditText` переводится в число;
2. если число невалидное, выводится сообщение об ошибке;
3. если всё нормально, создаётся `Intent`;
4. в интент кладётся число секунд;
5. вызывается `startService(intent)`.

## Как работает сервис

В `onStartCommand()` сервис получает значение из:

`EXTRA_SECONDS`

Если значение некорректное, сервис сразу делает `stopSelf()`.

Если всё нормально:
1. создаётся notification channel;
2. запускается корутина;
3. внутри корутины идёт `delay(seconds * 1000L)`;
4. после ожидания показывается уведомление;
5. сервис вызывает `stopSelf()`.

## Почему сервис одноразовый

Здесь нет бесконечного цикла и нет повторяющейся логики.

Сервис нужен только чтобы:
- стартовать;
- подождать;
- показать уведомление;
- самоуничтожиться.

Поэтому это именно одноразовый таймер.

## Как показывается уведомление

После завершения задержки вызывается `showFinishedNotification()`.

Там создаётся уведомление с текстом:
- заголовок: `Таймер завершён!`
- сообщение: `Время вышло`

Это полностью соответствует условию задания.

## Зачем нужен NotificationChannel

Начиная с Android 8.0 уведомления должны идти через канал.

Поэтому в сервисе есть `createNotificationChannel()`.

Без этого на новых версиях Android уведомление могло бы не показываться корректно.

## Что говорить на защите

Короткий вариант:

1. Пользователь вводит число секунд.
2. Activity передаёт это число в background service через `Intent`.
3. Service запускает корутину и ждёт через `delay`.
4. После ожидания показывает notification.
5. Затем сервис сам вызывает `stopSelf()` и завершает работу.
